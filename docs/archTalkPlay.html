🏗️ Arquitectura IntentTransformer

📐
Diseño Encoder-Only
Input Embedding
Capa: nn.Embedding(vocab_size, 256)
Vocabulario: 10,000 tokens (PALABRA: índice)
Output: (batch, 128, 256)
Positional Encoding
Tipo: Paramétrico aprendible
Dimensión: nn.Parameter(1, 512, 256)
Función: Captura orden secuencial del diálogo
Transformer Encoder
Capas: 4 x TransformerEncoderLayer
Atención: Multi-Head (8 cabezales)
FFN: 256 → 1024 → 256 (dim_feedforward)
Normalización: Pre-LN (LayerNorm)
Global Average Pooling
Operación: x.mean(dim=1)
Input: (batch, 128, 256)
Output: (batch, 256)
Propósito: Vector de contexto global
🔢
Clasificación Multiclase
Proyección Lineal
Capa: nn.Linear(256, 38343)
Input: Vector de contexto 256-d
Output: Logits para cada canción
Softmax + TopK
Función: torch.softmax(dim=1)
Salida: Distribución probabilidad
Selección: torch.topk(k=10)
Uso: Selección de candidatos
Forward Pass Completo
def forward(self, x):
    # x: (batch, seq_len) tokens
    x = self.embed(x)                    # (B, 128, 256)
    x = x + self.pos[:, :x.size(1), :]   # + Positional
    x = self.encoder(x)                  # (B, 128, 256)
    x = x.mean(dim=1)                    # Global Pooling (B, 256)
    return self.fc(x)                    # (B, 38343) logits

# Input: Dataset TalkPlayData-2 (conversaciones estructuradas)
# Estructura por fila:
#   - conversation_goal: {listener_goal: "relax"}
#   - user_profile: {preferred_musical_culture: "jazz"}
#   - conversations: [{role: "user", content: "..."}, {role: "music", content: "SONG_ID"}]

def process_dialogues(df):
    processed_data = []
    for _, row in df.iterrows():
        history = []
        goal = row['conversation_goal']['listener_goal']
        culture = row['user_profile']['preferred_musical_culture']
        
        for turn in row['conversations']:
            if turn['role'] == 'music':
                # Crear ejemplo de entrenamiento
                processed_data.append({
                    'input_text': f"Goal: {goal} [SEP] Culture: {culture} [SEP] " 
                                   + " [SEP] ".join(history),
                    'target_song': turn['content']   # Spotify ID
                })
            history.append(f"{turn['role']}: {turn['content']}")
    
    return pd.DataFrame(processed_data)

import json
import pickle

# 1. Configuración de rutas
SAVE_PATH = "/content/drive/MyDrive/ia2pdg/talkplay/transformer_checkpoint"

with open(os.path.join(SAVE_PATH, "vocab.json"), "r") as f:
    vocab = json.load(f)

with open(os.path.join(SAVE_PATH, "song_map.pkl"), "rb") as f:
    song2idx = pickle.load(f)
    idx2song = {i: s for s, i in song2idx.items()}

⚠️ Consideraciones de Deployment

• map_location='cpu': Obligatorio si el modelo se entrenó en CUDA pero se sirve en CPU
• model.eval(): Desactiva capas de dropout y batch normalization para inferencia determinista
• torch.no_grad(): Usar en forward pass para reducir consumo de memoria

Pipeline de Predicción
Función predict() completa
def predict(user_query, top_n=10):
    # 1. Tokenización
    tokens = re.sub(r"[^a-zA-Z0-9\s?]", "", str(user_query).lower()).split()
    enc = [vocab.get(t, vocab["<UNK>"]) for t in tokens][:128]
    enc += [0] * (128 - len(enc))  # Padding
    
    x = torch.tensor(enc).unsqueeze(0).to(device)  # (1, 128)
    
    # 2. Inferencia
    with torch.no_grad():
        logits = model(x)              # (1, 38343)
        probs = torch.softmax(logits, dim=1)
        values, indices = torch.topk(probs, top_n)
    
    # 3. Mapeo a IDs de Spotify
    results = []
    for i in range(top_n):
        song_id = idx2song[indices[0][i].item()]
        confidence = values[0][i].item()
        results.append({"id": song_id, "confidence": confidence})
    
    return results

@app.route("/predict", methods=["POST"])
def predict_endpoint():
    try:
        data = request.json
        user_input = data.get("lyrics", "")
        
        if not user_input:
            return jsonify({"error": "No se recibió texto"}), 400
        
        # Inferencia
        tokens = tokenize(user_input)
        with torch.no_grad():
            outputs = model(tokens)
            probs = torch.softmax(outputs, dim=1)
            values, indices = torch.topk(probs, 10)
        
        # Formatear respuesta
        results = []
        for i in range(10):
            results.append({
                "track_name": f"Track ID: {idx2song[indices[0][i].item()][:8]}...",
                "artist_name": "Recomendación EchoPulse",
                "similarity": values[0][i].item()
            })
        
        return jsonify(results)
    
    except Exception as e:
        return jsonify({"error": str(e)}), 500
