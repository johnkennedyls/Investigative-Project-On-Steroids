Arquitectura Híbrida End-to-End
Sistema de recomendación musical multimodal

EchoPulse AI combina LLMs (Qwen 2.5) para procesamiento de lenguaje natural, Transformers especializados (Módulo 3) para recuperación semántica de intención, y Transformers híbridos (Módulo 2) para re-ranking basado en features técnicos y léxicos. El sistema reduce un universo de 38,343 canciones a recomendaciones precisas en ~6-8 segundos.

Implementación PyTorch
IntentTransformer - Clase Completa
class IntentTransformer(nn.Module):
    def __init__(self, vocab_size, num_songs, d_model=256, n_heads=8, num_layers=4, max_len=512):
        super().__init__()
        self.embed = nn.Embedding(vocab_size, d_model, padding_idx=0)
        self.pos = nn.Parameter(torch.zeros(1, max_len, d_model))
        encoder_layer = nn.TransformerEncoderLayer(
            d_model, n_heads, dim_feedforward=1024, batch_first=True
        )
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers)
        self.fc = nn.Linear(d_model, num_songs)
        
    def forward(self, x):
        # x: (batch, seq_len)
        x = self.embed(x) + self.pos[:, :x.size(1), :]  # + Positional
        x = self.encoder(x)  # (batch, seq_len, d_model)
        x = x.mean(dim=1)    # Global Average Pooling
        return self.fc(x)    # (batch, num_songs) logits

Proyección: 26 → 256 → 512 + GELU

Fusión Cross-Attention

Key/Value: Técnico (batch, 1, 512)
Cabezales: 8
Output: Memoria fusionada
Decoder & Output
Capas: 6 TransformerDecoderLayer
Pooling: Global Mean
Output: Embedding 512-d de la canción

Re-ranking Híbrido
Cálculo de Score
# 1. Similitud Neural (Coseno)
query_emb = F.normalize(model(l_tensor, t_neutral), dim=1)
neural_sim = F.cosine_similarity(query_emb, song_embeddings, dim=1)

# 2. Similitud Léxica (Jaccard)
query_set = set(words)
jaccard = [len(query_set & s) / len(query_set | s) 
           for s in lyric_word_sets]

# 3. Ponderación final
ALPHA, GAMMA = 0.40, 0.60
score = (ALPHA * neural_sim) + (GAMMA * jaccard)

# 4. Top K selección
top_val, top_idx = torch.topk(score, k=10)
✅ Optimizaciones
• Embeddings pre-computados: 5,710 canciones en memoria
• NaN handling: torch.nan_to_num()
• Features neutros: Zeros para query sin metadatos
• Inferencia: torch.no_grad() + model.eval()

def procesar_consulta_echopulse(mensaje_usuario):
    # FASE 1: Traducción/refinamiento a inglés
    system_translate = "You are a music curator assistant. Convert the user's request into 3-5 concise English keywords..."
    query_en = query_hugging_face(mensaje_usuario, system_translate)
    
    # FASE 2: Módulo 3 - Top 10 por intención
    raw_m3 = module3.predict_top10(query_en)
    candidates_m3 = [enriquecer_candidato(c) for c in raw_m3]
    candidate_ids = [c["id"] for c in candidates_m3]
    
    # FASE 3: Módulo 2 - Re-ranking
    raw_m2 = module2.rerank_top10(candidate_ids, query_en)
    candidates_m2 = [enriquecer_candidato(c) for c in raw_m2]
    
    # FASE 4: Generar respuesta final con Qwen
    contexto = "\n".join([f"{i+1}. {c['track_name']} por {c['artist_name']}" 
                      for i, c in enumerate(candidates_m2[:5])])
    system_final = "Eres EchoPulse AI, curador musical empático. Responde SIEMPRE en ESPAÑOL..."
    respuesta_final = query_hugging_face(contexto, system_final)
    
    return {
        "response": respuesta_final,
        "module3_top10": candidates_m3,
        "module2_top10": candidates_m2,
        "stages": ["translation", "retrieval", "reranking", "generation"]
    }
